## 08:50 修复右栏动态空白 + 作物图标被裁切

  修复：`boot()` 中先 `currentActivity = fallbackActivity(); renderActivityList();`，实时数据到达后覆盖。
- 新增 `parseAgo()`（解析「更新于 2 天前」）+ `fallbackActivity()`（用内置 REPOS 的更新时间与 files[0].update 拼出动态）。
- `spriteForRepo()` 增加内置 REPOS 兜底，live 失败时也能取到正确作物图标。
- **图标裁切根因**：`sprites.js` 的 crop 坐标未对齐图集瓦片（如 cauliflower x=228、starfruit x=204/y=248），

- 动态图标 data-scale 由 3 降到 2；`.repo-item` 加 `min-height:34px` 以兼容不同高度的图标。
- 实测：动态 li 从 0 → 8；图标尺寸 26x44 / 28x52 / 32x30 均为完整精灵。

## 10:40 主题色优化：木色分级（重要教训）
- 用户反馈「有些地方看的有些别扭」。**根因**：上一轮把游戏里只做 4px 细边框的实测木框色

  - `--sd-wood-dk:   #853605`  边框/文字（实测）
  - `--sd-wood-lt:   #d9a45c`  浅木高光（柔和，非实测）

- 顶栏渐变改为 `#c8873c → #a04a12 → #853605`，底部保留实测金 `#dc7b05` 的 2px 细边
  （不再用亮金 #fa9305 做大面积起始色）。

### 实现
- `github-stardew.css`
  - `.dialogue-layout`：`grid-template-columns: minmax(0,620px) minmax(0,1fr)`，
    `justify-content: start`（靠左）、`align-items: start`（不互相拉高）、`gap:14px`。
  - `.card-pool`：由 grid 改为 **`display:flex; flex-wrap:nowrap`** 单行横向流，
    `overflow-x:auto; overflow-y:hidden`，`cursor:grab` + `.is-dragging{cursor:grabbing}`，
    `overscroll-behavior-x:contain`。
  - `.card-pool .villager-face`：`flex:0 0 68px`（单行内不压缩、不换行）。
  - 移动端（≤720px）：单列堆叠，卡片 `flex-basis:56px`。
- `github-gba.js`（卡池渲染处）
  - **滚轮 → 横向滚动**：`wheel` 监听把 `deltaY` 累加到 `scrollLeft`；
    横向已到头/尾且`scrollLeft` 未变时不 `preventDefault`，把事件交还页面，避免整页被锁死。
    必须 `{passive:false}`。
  - **拖拽横滑**：pointerdown/move/up，`|dx|<4px` 视为点击；`setPointerCapture` 跟随；
    拖拽过的卡片打 `_justDragged` 标记，松手后那一次 click 被忽略（防误切换说话人）。
  - wheel 监听挂在 `host`（`#villager-pool`）上；若元素不存在会回退到 `#villager-lineup`。

### 经验
- **纵向滚轮驱动横向滚动**：容器只有横向溢出时，必须手动把 `deltaY` 映射到 `scrollLeft`；
  且不要无条件 `preventDefault`，否则页面在卡池上滚不动。
- **拖拽 + click 冲突**：`setPointerCapture` 之后浏览器仍会派发 click，
  需用「位移阈值 + 一次性标记」区分拖拽与点击。
- 验证 headless iframe 几何时，`--dump-dom` 可能在 `setTimeout` 前抓取，
  需加 `try/catch` + 备用定时器重试。
