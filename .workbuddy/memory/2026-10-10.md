## 08:35 修复左栏项目间距与方框宽度（重要教训）
- **根因**：旧 `github-gba.css` 仍被页面加载，其 `.repo-list { display:grid; gap:6px }` 未被新样式覆盖。
  `.repo-list` 又是 `flex:1` 撑满左栏高度，而 grid 的 `align-content` 默认 `stretch`
  → 分类筛选后项目变少时，网格行被拉伸填满整栏，两个项目之间出现约 296px 的巨大空隙
  （实测：grid 295.8px → block 5.0px）。
- 修复：`github-stardew.css` 的 `.repo-list` 显式加 `display:block` 覆盖 grid。
- 方框宽度：`.repo-li/.repo-item` 加 `width:100%; max-width:100%; box-sizing:border-box; min-width:0`
  （实测方框 232px = 列表 232px，正好贴合左栏，不再溢出）。
- 顺带：`.cat-head` 间距改 `margin:10px 0 5px`；`.repo-name` 覆盖旧样式的 `text-decoration:underline` 与链接色。
- **教训**：本页同时加载 `github-gba.css` + `github-stardew.css`，改样式前必须检查旧文件里同名选择器是否有未覆盖的残留属性。

## 08:50 修复右栏动态空白 + 作物图标被裁切
- **动态空白根因**：`renderActivityList()` 只在 `buildActivity()` 里调用，而 `buildActivity()` 开头有
  `if (!live.ok && !liveEvents.length) return;` —— GitHub 未认证 API 限流（60 次/小时）时直接 return，
  `boot()` 里又从未调用渲染，导致动态面板永远是空的（实测 li=0）。
  修复：`boot()` 中先 `currentActivity = fallbackActivity(); renderActivityList();`，实时数据到达后覆盖。
- 新增 `parseAgo()`（解析「更新于 2 天前」）+ `fallbackActivity()`（用内置 REPOS 的更新时间与 files[0].update 拼出动态）。
- `spriteForRepo()` 增加内置 REPOS 兜底，live 失败时也能取到正确作物图标。
- **图标裁切根因**：`sprites.js` 的 crop 坐标未对齐图集瓦片（如 cauliflower x=228、starfruit x=204/y=248），
  切出来是跨精灵的碎片。用连通域分析重测了 12 个作物的精确边界（x,y,w,h），`crop()` 改为支持传入 w/h。
  外圈检测：12 个中 10 个 ring=0 完全独立，pumpkin/hotpepper ring=3（仅相邻精灵贴边，非截断）。
- 动态图标 data-scale 由 3 降到 2；`.repo-item` 加 `min-height:34px` 以兼容不同高度的图标。
- 实测：动态 li 从 0 → 8；图标尺寸 26x44 / 28x52 / 32x30 均为完整精灵。
- 文件修改：`github-gba.js`、`sprites.js`、`github-stardew.css`。

## 10:40 主题色优化：木色分级（重要教训）
- 用户反馈「有些地方看的有些别扭」。**根因**：上一轮把游戏里只做 4px 细边框的实测木框色
  （中棕 #b14e05、金高光 #dc7b05）当成大面积填充色用了，结果顶栏、`.file-icon`、
  `.readme-icon`、`.readme-badge`、`.speaker-name` 全被刷成刺眼的橙棕。
- **教训（务必记住）**：实测木框色偏红橙，只适合细边框/小面积高光；
  大面积填充必须用柔和木棕。游戏观感是「大面积柔和木棕 + 细边深棕/金」，不是整块橙棕。
- 修复 —— 木色拆成两级：
  - `--sd-wood:      #a8703c`  大面积填充（柔和，非实测）
  - `--sd-wood-dk:   #853605`  边框/文字（实测）
  - `--sd-wood-lt:   #d9a45c`  浅木高光（柔和，非实测）
  - `--sd-wood-gold: #dc7b05`  金色细高光（实测）
- 顶栏渐变改为 `#c8873c → #a04a12 → #853605`，底部保留实测金 `#dc7b05` 的 2px 细边
  （不再用亮金 #fa9305 做大面积起始色）。
- **验证手法（看不到图时很有用）**：用 PIL 对截图分区采样主色占比 + 按 HSV 找最饱和高频色，
  判断哪块「刺眼」。结果：顶栏高频橙已消失；左栏奶油 #fff8e6、中栏浅黄绿 #f3fadc、
  右栏 #e9f6cd、底部草绿 #5aa02f，整体协调。
- 保留判断：`.panel-bar` 的 `#b06a26→#6b3a10` 原本就沉稳，未改动。
